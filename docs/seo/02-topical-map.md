# 02 — Topical Authority Map (372 pages)

**Structure:** every category is one **Pillar** → **Supporting articles** → **FAQ pages** →
**Free tools** → **Landing pages**. The pillar is the only page that targets a head term; the
supporting pages target long tails and pass authority up to it.

**Notation**
- **Volume band** — `A` = est. 1,000+/mo global · `B` = 300–1,000 · `C` = 100–300 · `D` = <100.
  These are ranked estimates. Validate every `A` and `B` in Ahrefs/Semrush before writing;
  publish `C`/`D` on faith — long-tail volume is systematically under-reported and these convert
  best anyway.
- **Conversion** — `H` = searcher is close to buying · `M` = mid-funnel · `L` = top-funnel.

**Rule for every page in this document:** it must contain something a competitor's blog post
cannot — a playable role-play, a scored sample, a real rubric breakdown, or aggregate data from
your own users. Text-only pages lose to E2Language on authority. Product-bearing pages don't.

```

/oet/grammar/  /oet/vocabulary/      sub-pillars
/oet/scores/   /oet/exam/            sub-pillars
/oet/[country]/                      country hub
/nursing-english/                    adjacent-topic pillar
/careers/                            post-OET pillar
/tools/[tool]                        free tools
/compare/[competitor]                comparison landings
/learn/[slug]                        evergreen articles (migrate from hard-coded .tsx)
/blog/[slug]                         news, updates, results
```

Retire nothing that already ranks — 301 `/learn/*` to new locations only if the new IA is
genuinely better, and keep the redirect forever.
